Estudio **Ciberseguridad** en la Universidad Tecnológica de Panamá, sede Chiriquí. La mayor parte de lo que publico acá nace de trabajos de clase que terminaron siendo herramientas que uso de verdad: guías de repaso, portafolios de laboratorio y apps chicas para problemas concretos.

Trabajo casi siempre con **HTML, CSS y JavaScript sin frameworks**, para que cada proyecto abra rápido, funcione sin instalar nada y se pueda consultar desde el celular en el bus.
